# 九周材质课：从研究进入可实施教学的独立路线审查

审查日期：2026-09-20。性质：独立审查建议，未改变 canonical 决策，未合并 Issue #7 分支。上一轮八周审查不是本次前提。

## 1. 裁决与事实边界

**当前应该停止广域研究，进入真实练习与 Teaching Kit 的联合制作。缺少独立 Teaching Component Map 不是 blocker。现有九周结构可作为导航，但其中若干“不可裁剪”和“仅影响某一项”的断言应撤回。**

最有价值的下一步是：在实际教学运行时中，用选定主资产的一个可编辑表面，做出“观察→一次制作→指定区域修改→保存重开”的最小可教切片。它同时提供 W1 的实际起点，并检验后续最危险的操作假设。无需等七个角色都做成完整套件。

## 2. 真正改变路线的发现

### 2.1 新的缺口是可教路径，不是来源与组件数量

当前 main 的周程表已有：可观察表现、活动、反馈、证据、来源、风险、裁减项。Browser 提议的组件字段大部分已经存在。真正没有被证明的是：学生从哪个实际工程开始，完成哪些操作、怎样得到反馈、文件如何恢复，以及这条路径占用多少课堂与教师时间。

把现有段落搬入另一张矩阵不能回答这些问题。现在应从“每个重要主张有出处”转到“每个核心练习有可运行起点和完成样例”。教学指导支持目标、练习、反馈的对齐，不支持先穷尽可组合组件才允许实施。[CMU 学习原则](https://www.cmu.edu/teaching/principles/learning.html)

### 2.2 Pass C 不是只有 metadata 过细，而是已经悄悄改课

分支 `teaching-asset-pass-c-sourcing.md:173–202,281–308` 将非金属近迁移解释成釉面、开片、釉下彩、粗陶胎等复杂表现，并称之为完美测试。若学生此前只学涂层遮罩与基础通道，这可能考到新知识，而不是已学能力的迁移；若 starter 已预置正确分层，也可能把关键判断替学生做掉。

同报告第299行把未冻结的 Normal Bake placement 变成 W2 的45分钟实操；第302行把 W3 改写成微表面/几何表征；这不是资产位置标注的小细化，而是改变教学顺序与容量。

应删回提案身份并重新按依赖判断，不应为了报告内部一致而批准新课题。精确金属种类、釉下工艺和 F0 不能从漂亮外观直接认证；教学艺术设定可自行定义，但必须与资产来源事实分开。

### 2.3 “正交门禁”是有用的推进办法，不是因果事实

v0.2 第2节把硬件限定为只影响 exact render assumptions，LO3 probe 只影响 exact teaching path。实际存在跨项依赖：

- 烘焙等待、显存不足或运行时不可部署，可能改变 W7、W8 的形式与时长；
- LO3 若需要复杂图像管理或不同混合表示，会反过来改变 W3 的结构、W4 的参数化以及 W7 的烘焙；
- 停课且不能补齐时，日历会影响可教容量；
- 逐人反馈交不回来，会直接压缩下一周修订窗口。

保持这些问题不机械阻塞所有工作是正确的；预先禁止它们改变课程结构是错误的。应采用“先推进不受影响部分，若测试失败则局部重排”，而不是宣告影响永远局部。

### 2.4 不估分钟会掩盖超载；异步反馈也不会凭空增加容量

每班1440分钟已明确。v0.2 的 LOW/MEDIUM/HIGH 不能检验一周能否完成。应区别：

- **规划预算**：教师决定给活动多少课堂时间，超出时减到哪里；
- **完成时间估计**：根据试做或经验给区间，保留不确定；
- **实测**：特定学习者在特定起点完成的记录。

前两者不是伪精确，只要不冒充第三者。现在需要估计，而非继续拒绝数字。[CMU 排课指导](https://www.cmu.edu/teaching/designteach/design/contentschedule.html)也强调预留活动超时余量。

教师要带两班，因此总授课负担为48接触小时；学生各自仍只有24小时。示例敏感性计算：若一轮异步反馈平均每人5分钟，52人即260分钟，约4小时20分，尚未计文件打开、返修复核。5分钟不是实测，只用于暴露资源约束。

不能把每人两份 `.blend` 的全面差异核验当作常规形成性反馈。可以先看标准视角对比、局部说明与简短操作证据，源文件留存；对失败、歧义及轮换样本打开工程。抽查不是全面证明，最终个人达成仍需充分证据；一旦首次检查显示普遍问题，反馈模式要调整。

### 2.5 “终期作品质量优先”尚未充分体现在学习时间和首轮反馈时点

W1–W2 偏观察参数，W6 完整迁移，W7 交付，W8 首次综合评审，真正受支持的 texture authoring 与美术修改时间容易被挤压。W9 的一个精修窗口不能保证高质量。

建议让学生 W1 就做一次小但可见的材质决策，W3–W4 看主作品的第一版视觉方向；LookDev 从第一次赋材质就作为观察习惯出现，W8 才承担综合评价，而非首次接触视觉开发。

“作品质量”还应包括材质识别、视觉主次、尺度、设计意图与修改质量。若高质量主要来自原厂现成纹理、预置玻璃与灯光，不能全部算成学生材质创作能力。保留教师/厂商贡献并明确学生可编辑范围，比让学生从零重做全部材质更公平、更省时。

### 2.6 Texture authoring 可能被节点调参与合规排错挤掉

当前图表善于表达因果、遮罩、修改和交付，但“学生亲自制作什么表面信息”不够突出。需要至少一个学生可决定的局部标识、色彩布局、粗糙度分区或表面纹理，不是全程只调教师 Noise 与已有素材。

同样，程序化不是图中有8–12个节点，AI 不是有一张标成 AI 的坏图，反馈不是有一份 checklist。要检验学生实际选择、预测、制作和改正。

## 3. 九周结构：保留脊梁，改变颗粒度与顺序

保留六 LO 作为评价维度，无需再拆新 taxonomy。保留小主项目与独立迁移证据；保留两出口的最小行为和 W9 精修。没有证据支持全面换软件或恢复所有教材比较。

建议的条件性结构如下，它是本次设计提案，不是新 frozen schedule：

| 阶段 | 调整后的重点 | 必须保护的学习动作 |
|---|---|---|
| W1–W2 | 观察、少量参数因果、第一次小范围制作；用已知场景学会保存和重新打开 | 预测→亲手改变→观察→说明；早期发现 Blender 基线问题 |
| W3–W5 | 主资产表面创作、局部绘制/遮罩、可解释变体与反馈修改 | 至少一次较早的视觉方向点评；LO3 二次修改；AI 作为输入决策进入制作 |
| W6 | 短独立迁移＋主作品集中修订，可含早期交付检查 | 保留陌生条件下独立判断，释放余下课堂给主作品 |
| W7 | 受限输出、一次外部验证；处理真正影响视觉意图的差异 | 不把手动打包、多资产复制或格式百科当成成效 |
| W8 | 主作品综合评审与当堂修改；检查遗留问题 | 反馈在最终截止前可用；允许未确定原因，不强迫学生编造归因 |
| W9 | 主作品精修、提交与复盘 | 有已明确的修改优先级，不首次发现结构性失败 |

可以在早期做一个很小的目标导出烟测，避免 W7 才发现整条材质表示不能可靠输出；不是重跑多引擎验证。教师路径用最终拟教的结构验证，学生仍在适当周次学习交付。

## 4. Component Map：接受检查思路，拒绝新必经层

“能力＋动作＋证据＋前置＋成本”是好的教学设计检查表；它们不是可以任意拼装的独立积木。

- 同一概念在教师示范、辅助练习、独立任务中的成本不同；
- 共享主资产可减少重设，也可能把早期错误传递到后续任务；
- 两个活动各自可行，不代表同一160分钟或同一周教师反馈容量下可行；
- 艺术判断往往要多轮观察与修改，不是一次覆盖就“完成组件”；
- 资产、任务与顺序会相互修改，不能纯单向由库存拼出课程。

**不建议新增独立 canonical Component Map。** 当前 v0.2 第10节已经接近 Course Assembly Map。只把关键行补成下面五类信息即可，能复用就不复制：

1. 学生动作与本轮达标证据；
2. 起始工程/资源指针，以及已经教过的必要能力；
3. 课堂预算、课外是否必需、估计依据；
4. 谁反馈、何时返还、学生在哪里修改；
5. 若超时或运行失败，保留什么、删什么。

来源使用现有链接；不新增组件ID、47项全映射、节点清单、成熟度评分、许可重复表、组件注册表或独立 PASS。若团队确实需要临时组件草图，把它限制为既有周程表的一个视图；一旦不能改变先后顺序或删减决策，就停止维护。

不必先“完成全部粗装配”再深写 W1。当前已有粗装配，做一次冲突检查后即可制作 W1；用实际试做结果回写剩余周次。

## 5. Issue #7：发现研究可以停止，套件就绪尚不能宣告

本轮有界核查只涉及两件首选，不扩展候选目录。来源：[手电页面](https://polyhaven.com/a/vintage_flashlight)、[花瓶页面](https://polyhaven.com/a/antique_ceramic_vase_01)、[官方许可](https://polyhaven.com/license)、[手电 files API](https://api.polyhaven.com/files/vintage_flashlight)、[花瓶 files API](https://api.polyhaven.com/files/antique_ceramic_vase_01)。

核查结果：

- 页面标明 CC0，API 列有实际 `.blend`、glTF、FBX 等文件。读取了小型 glTF JSON，但未下载几何二进制、完整贴图或打开 Blender 工程。足以进入候选试制，不足以认证教学就绪。
- 手电当前页面/API 只有1K、2K、4K，报告的1K–8K不准确。这不是继续采购研究的理由；改掉或不承诺8K即可。
- 手电页面/API没有列出 Curvature；不能承诺“官方曲率图直接打包”。也不能据此断言其 `.blend` 内绝无相关数据。如果练习依赖它，必须验证或改用更简单遮罩。
- 花瓶 Mask01–03 确实存在；没有确认每张图代表釉、胎或裂纹。也不能假定下载 `.blend` 已包含额外 mask。
- glTF 中有 `TEXCOORD_0` 不证明无重叠/无拉伸；用于指定区域独立绘制时，UV 别名会直接影响 LO3。要检查教学范围内的可编辑性，不必先审计每个UV岛。
- 官方外观描述可支持“旧红色工业手电”“有开片视觉的陶瓷”；不足以认证报告中具体冷轧钢、镀层工艺、钴蓝釉下彩、精确 F0 或微裂纹的表示来源。
- 手电 glTF 的玻璃使用 alpha BLEND，未声明 transmission/ior 扩展；它不是报告所称玻璃物理折射完整性的证明，也不能外推 `.blend` 的全部节点行为。
- 教师准备少于1小时、45分钟或全套8小时均没有本轮实测支撑。Role 5 在 matrix 仍明确 MISSING，与“全部落实”相矛盾。

**建议 disposition：两件首选保留为 ADOPT_WITH_PREP，明确含义是“选作试制候选、未完成教学工程验收”。** 这足以结束候选发现，不需要证明“最佳”。

### 当前最小充分证据的停止边界

| 阶段 | 必须知道 | 可以停止/延后 |
|---|---|---|
| 来源选择完成 | 精确资产来源；许可与目标使用范围；实际文件可取得；大致规模；为什么满足一个必要教学动作；尚存什么风险 | 不追求全候选排名、面数尾差、所有分辨率、精确材质物理名称 |

| 分发 Teaching Kit 前 | 指定版本下实际起点/步骤/恢复有效；图像和工程能保存重开；分发边界与来源记录；主流程在代表性设备可运行 | 无教学收益的几何优化、多个备用完整套件、全机型性能矩阵 |

这些不是三个新 Gate，而是不同决定所需的证据范围。采用研究可以收口，工程准备继续在真实练习工作中完成。无需为了保持 Issue #7 OPEN 就继续搜索，也无需为关闭 Issue 而把未完成项改成 READY。

### 许可审计也需要收敛

保留第一方许可与使用边界，不用“零法律风险”措辞。课程内部授权不自动扩大成公开仓库分发授权。

避免 NC 资产以简化学生后续用途，是可成立的课程政策；“NC 资产用于任何求职作品集均侵权”不是已证明结论。CC 官方解释需要按具体使用目的判断，不能只凭使用者或场景标签定性。[CC FAQ](https://creativecommons.org/faq/#does-my-use-violate-the-noncommercial-clause-of-the-licenses)

无需为此恢复 DamagedHelmet，也无需追查所有被排除资源。将排除理由改成项目使用范围偏好即可。技术不适合 starter 与法律禁止分发，也应分开。

## 6. 关键教学项的容量裁决

以下分钟数均为**建议预算范围/取舍上限，不是实测或文献规定**；必须从既有1440分钟中置换，不能额外叠加。

### Near-transfer：必要的是证据，不是完整一周或陌生模型本身

建议在 W6 先预算25–40分钟独立判断/局部操作，再用10–15分钟做共性反馈；其余时间回到主作品。若试做需要更久，先减任务面，不机械取消独立性。

只换模型而仍逐步照抄不算迁移；同一熟悉模型遇到新的材料目标、限制或错误，也可能形成有效近迁移。故“石膏之前见过就绝对不能用”以及“平面缺复杂体积所以不合格”都是过强要求。现阶段无需为迁移重新采购更复杂物体。

花瓶可使用，但只测试已教内容，例如选择非金属响应、诊断 roughness/尺度问题、在限定区域修改并说明哪些工业规则不能照搬。不要考核未教的釉下散射、SSS或多层光学。三分类表可缩成对一个具体决策的说明，六项形式不应享有不可裁剪地位。

### Normal Bake：保留表征理解；不强制完整独立操作

最低目标是学生能比较 high、low、low+normal，解释 normal 改变着色法线而不是补回所有几何，指出轮廓等仍有差异，并理解 high→low 表征烘焙与 W7 材质图→贴图输出不是同一教学任务。

优先选择**教师演示生成＋学生开关/旋转对比与诊断**，预算约20–30分钟替换现有 normal 讲解。如果实际套件顺畅、班级设备允许，可升级为约30–40分钟支持操作；不要把“每人必须亲自配置并成功烘焙”设为核心最低证据。

依赖位置是“理解法线方向、图像数据、UV映射后，第一次需要使用法线细节前”，通常可在 W2 尾或 W3 起，但先满足依赖再决定周次。出现投射/cage排错就用教师已知正确结果恢复；不把短实验升级为修复生产烘焙技能。

旧雕塑包若准备困难，简单浮雕 high/low 对照也能达到目标。存在老案例不是必须复用它的理由。Blender 官方手册支持 Selected-to-Active 与 tangent-space 的技术机制，但不证明这个班需要多长时间。[Blender 4.5 烘焙手册](https://docs.blender.org/manual/ja/4.5/render/cycles/baking.html)；5.2 的实际操作仍待试制验证。

### Procedural：规模可以小，学生独立性不能只剩拖滑块

当前 bounded scope 合理；不需要 Designer，也不需要8–12节点指标。直接让 W3 的材质结构在 W4 增加一个可解释控制，Role 5 可成为同一工程的教学状态，而不是独立资源采购/制作项目。

学生至少解释输入关系，独立更改一段映射或连接，预测并得到两个有意义的结果。只有在教师封装图上随机改 seed，不足以证明 parametric thinking。也不要把所有变化等同于加噪声、做旧。

### AI：无需加一周，但“只有识别坏图”不足以兑现 workflow 定位

三种长期方向不等于本学期平均分三份。可以保持 W4 的小范围对比，但应完成一次实际选择闭环：给定意图，比较检索/AI/自行制作备选，逐通道选择，接受一部分并整合，或有据拒绝并执行替代方案。

教师可事先提供实际 AI 输出与来源说明；不要求全班注册账号或学习提示词大全。保留好坏混合样本，不暗示“AI必错、图库必对”。如果学生全过程不尝试选择后的使用/替代，课程只能诚实称“AI literacy/QC入门”，不能宣传生成式创作熟练度。

### Realtime＋LookDev：保留不同问题，压缩重复实现

- 外部 glTF 验证检查材质数据跨应用能否正确交付；
- LookDev 检查视觉意图在照明/视角变化下是否成立。

二者有不同价值，不需要各占一整周的全新教学内容。LookDev 应嵌入日常制作，W8用于综合点评；WebGL保持一次模板化输出。参考地砖可作教师排错控制，不必让全班再做一遍地砖管线。

在保留材质不能直接输出时才烘焙；不是所有材质都必经重复bake/手动ORM打包。不能为迎合导出器删掉必要作者能力，也不能以学习交付为由教完整游戏管线。能做 WebGL 检验不等于拥有游戏生产能力；Cycles 对照不等于影视资产生产。

## 7. 比新 Map 更重要的遗漏

1. **课外工作假设**：当前知道24小时接触时间，仍不知道学生可用机器和每周课外投入。先让最低合格路径在课内受支持完成，精修课外部分明确为另一个负荷，或取得可实现的作业预算。不能用“最终质量优先”默许无限家庭作业。
2. **学生贡献范围**：原厂模型、法线和非教学部位可以保留；明确学生负责哪些表面信息与决策，否则难评作者能力，或反向要求不必要的从零重建。
3. **最小恢复路径**：某周卡住的学生如何从已知正确起点继续学习下一项，而不永久落后？每个关键练习一个恢复文件/状态，通常比完整组件体系更有用。
4. **反馈时点与预算**：W8的评审若课后迟迟返还，W9精修失效。先选反馈产物与返还日，再决定交几份文件。两班同标准不要求所有过程题完全同样；等价的参数/错误变体可保留独立判断证据。
5. **评价标准不必等待权重**：学校政策未明可以阻塞最终百分比，但不应阻塞定义材质识别、视觉主次、修改质量和交付完整性等可用标准。

## 8. 认真考虑的相反结构

可选方案是“前三周短材质样本循环，后六周集中一个受限主作品”，不要求主工业资产从 W1 贯穿：

- 早期用球、板、浮雕等简单几何做因果、图像制作与法线表征；无需等待外部主模型才可开课；
- W4进入主作品，用已学组件完成作者意图和局部修订；AI输入决策嵌入主制作；
- 迁移做短未知简报或错误诊断；W7前得到主要视觉反馈，后期集中交付与精修。

优势是早期操作与资产风险低，建立组件理解更直接；缺点是主作品积累时间较短，容易形成脱离作品的练习。因此不宣布它更优。但若主模型试制仍迟迟不能成立，此路线可以让 W1 先可教，不必暂停整门课程。

另一种无需推翻主线的变体：整件手电作为展示载体，只让学生创作一个壳体表面及少量关联区域，玻璃/反光碗由教师提供。它可能更符合最终质量优先和24小时约束。资产连续性可以服务学习，但不应要求同一资产承担所有技能演示。

## 9. 接下来三个 Work Units

### WU1 — 做出主资产的最小可教切片

**解决什么**：确认候选能成为教学起点，验证核心局部编辑路径；给 W1 一个真实文件。

**为什么现在**：这是资产、软件、LO3与后续输出的交点，继续做表格不会减少其不确定性。

**实际产物**：只取一个首选的低分辨率工程；划定学生负责的表面，保留必要几何法线/非教学部位；提供稳定观察场景。教师在目标 Blender 中做一次局部图像/遮罩修改，检查保护区、保存图像与工程、真正退出重开、追加修改。对所教表示做一次极小外部输出检查，避免晚期才发现路径不成立；无需把全部资产完成成品。

**停止标准**：有一个可打开起点、一个修改后结果、短步骤与恢复办法；来源/许可保留，实测环境和未测设备清楚。若主资产确有阻碍，只处理一个实质问题或用简单教师壳体恢复，不开启候选海选。

**不做**：制作全部七角色、全面UV审计、精美Reference、完整最终材质、批量自动化平台、Painter普查。Teacher dry run 不冒充学生试教或机房部署通过。

### WU2 — 制作并试走 Week 1 的160分钟课程包

**解决什么**：从架构进入教师真能照着教的一节课。

**为什么现在**：已有整体导航，不需等待全部未来内容；W1能暴露界面、基线、文件与反馈摩擦。

**实际产物**：短教学脚本/讲义、学生任务单、WU1起点、已知正确结果/恢复状态、统一提交方式。明确观察与一次小制作、学生证据、课堂反馈和结束前保存重开。做一个真实160分钟的预算，含入口诊断、演示、练习、反馈、修订与缓冲；所有时长标为计划或实测，不用 LOW 代替预算。

**停止标准**：教师可按包执行，必做活动及删减项清楚，文件可恢复；最好由接近学生基线的人试做关键步骤，若无人可试则保留风险。核对代表性机房部署，不以教师机替代全班条件。

**不做**：九周逐字稿、完整组件注册表、全套录屏、为未公布政策发明成绩比例。未来 LO3 若仍条件性，不阻塞不依赖它的 W1任务。

### WU3 — 用试做结果修订现有全局表并安排下一段练习

**解决什么**：用真实操作成本完成课程取舍，避免逐周局部优化。

**为什么此时**：已有至少一个实际教学切片与W1路径，时间账不再完全靠想象。

**实际产物**：直接修订既有 v0.2 表的容量、前置与反馈栏目；确认课外预算与教师反馈可用时间；压缩 W6，确定 Normal 实验的演示/支持操作级别；让 procedural 与 AI 回到同一制作闭环；标出早期视觉点评。只为紧接着要教的练习制作缺失文件。

**停止标准**：每周必做计划落在160分钟，课外负荷明确，教师能在下一次修改前返还关键反馈；没有一个尚未存在的工程被当作 READY；学期后段保留可用的主作品修订时间。

**不做**：重启全资源研究、重排47项、将每个可选材质建成独立模块、把低置信度估时包装成已验证。

WU1 中遇到具体局部编辑摩擦才启动 Painter 的同任务比较；无需等待 Blender 技术上完全不能做。硬件/部署核对可与这些工作并行，其结果允许局部改变课堂形式。

## 10. Recommended Next Move

**批准一个主候选进入最小教学切片试制，结束 Issue #7 的候选发现；不要新建独立 Component Map。**

在分支被采纳前，一次性更正“全部闭环/极低工时”的断言，移除 Pass C 偷渡的排课决定，保留未完成项即可。不要再对每个装饰性 metadata 开一轮审阅。

下一次交回的核心应是可打开、可修改、可恢复的实际工程与 W1 起点。它比另一份“知识与资产均已映射”的文档更能推动真正开课。
