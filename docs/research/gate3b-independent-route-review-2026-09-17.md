## A. 真正需要改变的路线

**CURRENT AGENT JUDGMENT**：不是再比较哪套教材覆盖最多，而是先拆开三件事：学生必须证明的能力、实现能力的表示方式、教师借用的教程。现有路线仍容易把三者绑成一条链。

四项承重问题：

1. **LO3 确实预置了 Painter 式表示。** 原文第 157–173 行要求非破坏多通道图层、几何贴图自适应遮罩、清晰图层组织和锚点链接。随后 3B 第 189 行宣布 Painter 为唯一核心宿主。这是带有选择偏置的推导；遮罩本身是工具无关概念，但这组独立实操要求并不工具无关。
2. **试题也可能继续偏置。** 以“多层锈蚀、掉漆、几何生成器、二次依赖”为代表，实际上先选中了专门纹理绘制器擅长的工作。必须先证明这些复杂度在本课不可删，否则干跑只是在验证预设题目。
3. **单一主资产不是低成本的充分条件。** 强行让电视机兼任程序化、AI 质检、光学观察和交付实验，可能增加补丁，并把“材质制作”窄化为“旧硬表面道具做旧”。连续作品的吸引力不能替代跨载体迁移证据。
4. **总负担尚未定义，因而没有可证明的全局最小值。** 免费软件可以有很高的备课成本；付费软件也可能节省支持成本。需要考虑准备、入门、练习、修改、文件恢复、交付、部署和下年度维护。不要把这些异质成本硬合成一个伪精确分数。

还需纠正两个非 LO3 问题：

- **LO5 隐含“必须修好输入”。** 3A 第 218、232 行把生成通道与去光照成功写入表现。建议允许有依据地拒收、换源或只使用可靠通道；若任务明确要求修复才评价修复能力。识别不能可靠恢复的信息，也是一种材质判断，不能迫使学生把坏素材“加工合格”。这需要显式调整实现解释，不能假称已满足现有全部字面要求。
- **LO4 也有表示偏置。** 第 202 行的“3–5 个暴露参数”、无缝表面和封装要求不应自动成为最低能力。最低证据可以是学生解释一个输入如何改变分布/尺度，主动创建有意义的变体并辨认失败。节点是合理实现，不要求每人完成可复用产品级节点组。

## B. Blender 与 Painter 的裁决

**CURRENT AGENT JUDGMENT**：Blender-only 具有真实可行性，可以完全不教 Painter；目前证据尚不足以宣布它在本校最低成本。该结论针对去除表示绑定后的 LO，不针对“完整复刻 Painter 工作流”的要求。

学生不可删的知识是：外观属性与光照的关系；表面空间位置如何指定；多个属性何时共享空间分布、何时应分开；编辑的影响范围与依赖；源工程和交付贴图的区别；在变化条件下复核意图。它们不专属于 Painter。

**TEACHING HYPOTHESIS**：Blender 的最小候选不应是手动同步重画全部通道，而可以是“少量材质属性 + 一张可绘制区域 mask + 可解释的混合关系”。绘画决定位置，节点决定关联；必要时烘焙为目标贴图。保留独立属性控制，不要求所有通道机械地复用完全相同的纹理。这个方案必须接受保存、重开、二次修改和导出检验。

Painter 的 layer stack、anchors、智能材质和批量导出，主要提供组织、反馈与生产效率；其效率可能具有教学价值，因为它能把时间还给观察和修改，但功能存在并不能证明必修。没有发现某项本科概念只能通过 Painter 学会。

**Painter 入课的充分理由**应是：在同等任务标准下，Blender 需要维护难解释的依赖或反复手动同步，而 Painter 明显减少学生直面概念与教师恢复负担；且可用授权、机房和学生练习途径成立。比较的是总负担，不只是熟练教师修一次材质的速度。

| 结构 | 本轮判断 | 何时改判 |
|---|---|---|
| A Blender-only | 当前可撤销候选 | 小而透明的实现仍在真实修订/交付上产生持续阻碍 |
| B Blender + minimal Painter | 条件性后备 | Painter 的收益覆盖其新增学习、授权、部署和维护成本 |
| C Painter-centered + Blender support | 目前不采纳 | 只有资产贴图确实占保留任务的大部分、教师与部署已有明显优势时再考虑；一个局部任务胜出不够 |

**Designer / Sampler：移出必修，也不预留必做软件演示。** LO4 可由现有节点环境实现，LO5 可判断有来源说明的外部/AI 样本并作有限修订。只有出现现有工具解决不了的明确教学需求才恢复。三种生产范式不要求三套应用，也不要求每人亲自运行三个生产系统。

## C. 工具无关的 LO3

建议名称：**材质构建与有边界的受控修订**。

> 学生能根据参考与艺术意图构建材质；收到修改要求后，明确应改变的区域和外观属性、应保留的部分及合理的关联变化，选择足够可编辑的表示完成修订；能继续处理追加修改，检查非预期影响，并用修改前后证据解释修改是否达成意图。

最低证据：

- 一个能够继续修改的源工程，编辑结构足以应对当前任务；
- 修改前、修改后与追加修改后的可比较结果；
- 能指出“改了什么、为什么、影响到哪里”，以及如何恢复或继续修改；
- 检查非目标区域/属性，并区分数据被误改与光照、反射造成的正常视觉变化。

不强制 layer stack、anchors、几何生成器或永久无损历史。图层、节点、独立图像、区域选择、参数和合理版本保存都可成为证据。版本保存不是解释能力的替代，也不能用每次从头重做来掩盖无法定向修改。

评价中的不变量应主要是非目标数据与设计意图，不能要求换光之后高光像素仍不变；应改变的相关属性也不能为了“保持通道稳定”而被错误锁死。

## E. CG Cookie 4.2 与 5.2 runtime

**CURRENT AGENT JUDGMENT**：V1 足以作为 Blender practice evidence 的起点，不值得仅为 Gate 3B 购买 V2。读目录只能确认覆盖主题，不能确认透明度、第二次修订与维护成本；必须用用户实际持有的 V1 选中课段和工程检验。

“旧参考 / 当前 runtime”分离合理，但有两种不同成本：教师借用方法自行示范，版本差异通常局限于选中段落；学生逐步照着旧视频完成作业，则界面、快捷键和结果差异会反复进入支持队列。两者不能按同一维护预算计算。

仅在下列差异被实际发现时，V2 才可能改变决定：

- 新版重做了本课需要的绘制、共享区域控制或烘焙/导出段，并显著减少手工补丁；
- 可直接用的新工程消除了当前文件缺失、依赖或迁移障碍；
- 学生必须逐课跟视频，而关键步骤持续失配。

新增本课不用的课程、更新总体营销描述、版本号更近，都不是购买理由。选中工程复制后在机房拟用的稳定 5.2 补丁版做窄验证；课程期间冻结该版本与源文件副本。不要承诺所有 4.2 工程无损迁移，也不必迁移九门课程。具体外部核验见文末。

## F. 实践结构

**TEACHING HYPOTHESIS**：优先采用 **两个核心 lab + 一次小迁移检查**，共享观察、修改、验证语言。数量是设计建议，不是新的最小性定理。

| 实践载体 | 核心表现 | 复用策略 |
|---|---|---|
| 简单资产上的局部材质制作 | 观察、构建、两次修改、局部性与属性关联 | 从现成工程取一个部件，保留可展示成果 |
| 小型表面/材质样本的程序变体与外部输入比较 | 解释参数、选择/拒收 AI 或检索输入、验证尺度和响应 | 借 CORE 相关练习，不复制整门课程 |
| 陌生载体上的小迁移检查 | 脱离原教程仍能做一个改动并验证 | 复用已有资产；不是第三个完整作品 |

LO1/LO2/LO5/LO6 可反复出现在同一任务，不能按六个 LO 自动切成六个教学单元。AI 在早期以可质疑的候选输入出现，后续再接受修订与交付检验。

一套统一 brief 和最终展示可以保持课程连续性；不需要一台电视机占 70–80% 实践。选择新净塑料、陶瓷、木材等普通材质与做旧金属作适度对照，是避免“做旧即真实”的设计方向，不是新增完整材质百科任务。

## G. 唯一最高价值验证：可恢复的双实现材质闭环

**CURRENT AGENT JUDGMENT**：保留 Representative Material Loop，但改成**从可用起点到重开、追加修改及交付的双实现教师干跑**。不能只比较画笔或改遮罩的局部速度，也不能把两条路径的烘焙/导出成本当成共享常量而漏记。

具体执行：

1. 从已有、带规范 UV 的资产取一个简单部件，例如涂漆外壳；两端使用相同几何、参考、目标外观和交付条件。允许各自采用成熟且简明的原生实现，不要求 Blender 复制图层，也不禁止 Painter 用图层。
2. 开始前，用一页纸写清必做表现与总容量情境。资产输入可预置；所有教师替学生做掉的 setup 都计入准备负担。记录教师熟悉哪套工具，避免把熟练度误当软件优势。
3. 构建基本材质。修改一：在指定接触区域改变磨损分布，并体现相应外观属性关系；保持标识和其他区域的意图。不要直接要求锚点、几何生成器或复杂多层锈蚀。
4. 保存、关闭、重开。修改二：改变同一区域的范围，再单独调整其中一个外观属性；验证共享控制能否局部解耦，检查非目标部分。由干跑者口头指出控制位置与依赖，不以完成截图替代解释。
5. 将每条路径各自的结果输出为同一目标接受的材质资产包，在同一个干净目标中打开；改变灯光/视角，预测并解释差异。选择已可用的轻量目标，不引入完整引擎课程。
6. 留下源工程、实际交付包、修改前后图和一页观察记录。记录准备、查资料、操作、重开恢复、烘焙/导出及故障处理；学生需理解的概念和无法解释的依赖应明确列出。时间、步骤、节点数只是观察。

若只做最简单的颜色改动，两端都可能轻松通过，无法暴露属性耦合；若一上来做任意复杂的锚点链，则任务又在偏向 Painter。上述“共享区域 + 合理关联 + 后续独立调整”是值得保留的最小压力点。

**证据门槛：**输出满足事先写明的意图；追加修改可定位且能解释；没有为了完成任务而维护一套隐蔽的通用图层系统；交付包可独立打开；准备与支持负担能进入课程容量账。没有分钟数、节点数或点击数的通用及格线。

**决策规则：**两者都清楚可教时，按 Owner 的少软件偏好保留 A；Blender 为保留能力付出持续复杂性、Painter 明显消除它且部署成立时选 B；两者都负担过重时先减任务复杂度；只有多项保留任务共同指向 Painter 才考虑 C。

这项试验可支持“是否加入 Painter”，不能证明整门课学习效果、陌生载体迁移或 C 的全课 ROI。教师干跑不能外推学生完成时间，也不能产生课堂踩坑率。若 Painter 当前无法取得，结果必须标为比较未完成，不能声称 Blender 已胜出。

**另一个更高优先级的未知是容量输入，而不是第二个技术实验。** 学时和学生先修条件若完全错误，软件探针再好也无法救课程。无需正式 student pilot；把已知教务输入写到同一页纸，未知项保留情境和删减后果即可。

## I. 最短关键路径与 Week 1–8

**VERIFIED PROJECT FACT**：纠偏评论已允许 3B 使用窄可行性探针，因此没有必要再发明一个流程来突破 3C。正式 Week 1–8 仍 blocked。

**CURRENT AGENT JUDGMENT**：建议允许现在就做一页**容量草图**，无需等软件完全冻结；它与发布可执行周程不是同一成熟度。可以让开始阶段承担观察和基本构建，中段承担修改与程序变体，后段承担独立判断、交付和再修订，并显式留出恢复、反馈、再提交的空间。此处不编排正式周程。

完全禁止任何时间草图，会让内容选择失去容量反馈；但草图必须标明“条件性估算，非教学承诺”，且此建议不自动改变 tracker 状态。实际学时未核实时，不能引用 56–72h 宣布已适配。

最短路径：

- 当前 V2 [Materials](https://www.cgcookie.com/courses/core-5-2-fundamentals-of-materials) 与 [Texturing](https://www.cgcookie.com/courses/core-5-2-fundamentals-of-texturing) 目录包含材质节点、PBR 纹理、Texture Paint/masking、程序化与烘焙等内容。这里核验的是 V2，不能回填 V1 的课数、深度或作业结构。本轮未取得 V1 精确课表，也没有证据声称 V2 已解决本课程受控修订问题。
