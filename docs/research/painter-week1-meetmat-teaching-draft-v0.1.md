## 1. 教学定位与整体介绍 (Course Orientation & Lesson 1 Scope)

### 1.1 课程宏观定位与开场声明 (Course Orientation — 15 分钟)
作为 9 周连堂课程的第一周开场，主讲教师需用前 15 分钟向学生明确课程的宏观图景与红线，解除学生的先修焦虑：
1. **核心聚焦材质本身 (Material / Texture Authoring)**：
   - 本课程的核心使命是学习**物理真实（PBR）材质创作与贴图绘制**；
   - 建模、人体拓扑、高低模包裹、展 UV 是材质制作的**支撑性前置知识**，教师会在后续课程中提供展开良好、法线干净的规范工业与雕像资产。课程绝不会在第 3 讲突然让学生手动画肌肉拓扑来作为考核难点；
2. **九讲能力演进阶梯**：
   - 从第 1 讲的 MeetMat 入门认知，到塑料、木材、金属、石材、织物、次表面半透明与自发光，最终在第 7–9 周完成全新独立的综合期末大作业；
3. **考核评价导向说明 (不冻结具体比例)**：
   - 课程遵循“最终作品质量优先”原则，同时重视课堂内的物理因果理解与过程证据；
   - **第一讲声明**：第 1 讲不设正式计分平时作业，以“熟悉软件环境、掌握物理通道、建立正确保存习惯”为考核前哨。

### 1.2 为什么第一讲选用官方 MeetMat 资产？
- **零门槛标准几何体**：`MeetMat` 是 Allegorithmic / Adobe 官方为材质挑战赛定制的标杆测试模型；
- **分层材质集 (Texture Sets)**：模型天然划分为 `Head`（头部）、`Body`（身体）、`Base`（底座）三大纹理集，能够让初学者在第一堂课直观理解多材质球与模型部位的解耦关系；
- **规范的 UV 与网格烘焙**：内置资产已预置高质量曲率（Curvature）、环境遮蔽（AO）与法线（Normal）贴图，杜绝外部资产因尺寸异常、法线翻转或缺少烘焙贴图导致的生成器失效问题，实现“开箱即用”。

## 2. 第一讲六步教学主线设计 (Six-Stage Pedagogical Loop)

依据教师已接受决定，第一讲坚决打破“先讲 40 分钟抽象光学理论再上机”的死板模式，严格贯彻**“直观感知 $\to$ 动手体验 $\to$ 理论升华 $\to$ 迁移应用”**的六步认知规律：

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│                            第 1 讲“六步递进”认知与教学组织主线                               │
├─────────┬──────────────────────┬─────────────────────────────────────────────────────────────┤
│ 阶段    │ 教学环节             │ 核心认知目标与师生活动                                      │
├─────────┼──────────────────────┼─────────────────────────────────────────────────────────────┤
│ Step 1  │ 视觉观察 (5 min)     │ 观察现实材质高光与 MeetMat 质感，产生“高光会跑”的视觉悬念   │
│ Step 2  │ 必要界面认识 (15 min)│ 载入官方 MeetMat，掌握视口三键客、光照旋转与 Head 纹理集    │
│ Step 3  │ 教师示范 (15 min)    │ 示范 Head 单色底漆 Fill Layer 与第二层 Black Mask 开窗绘制  │
│ Step 4  │ 学生操作 (25 min)    │ 学生动手在 Head 上实操调参（Roughness 变化）并体验遮罩涂抹  │
│ Step 5  │ 理论解释 (20 min)    │ 结合刚才的动手体验，讲解能量守恒、金属度、粗糙度与遮罩数学  │
│ Step 6  │ 独立应用与持久化 (40m)│ 独立微调 Head 配色，执行规范保存、退出软件与重开核验        │
└─────────┴──────────────────────┴─────────────────────────────────────────────────────────────┘
```

### 2.1 阶段一：视觉观察 (Visual Observation — 5 分钟)
- **教学引导**：通过投影展示两组强对比图像：
  1. 一组是现实中光滑塑料球与粗糙磨砂球在旋转光源下的光斑表现；
  2. 另一组是经典错误案例（在颜色贴图上画死白色高光，转动视角时光斑纹丝不动，严重穿帮）。
- **建立悬念**：向学生抛出核心问题：“为什么游戏里的模型换个角度看，高光会跟着走？三维软件里的‘高光’到底存在于哪里？”

### 2.2 阶段二：必要界面认识 (Minimal Essential UI — 15 分钟)
教师带领学生开启 Substance 3D Painter，仅认识第一堂课**绝对必要的 4 个核心区域**，坚决不作全菜单走马灯背诵：
1. **载入官方资产**：点击菜单 `File -> Open Sample... -> MeetMat`（官方原生内置，零外部文件依赖）；
2. **3D 视口与核心导航**：
   - 围绕观察：`Alt + 鼠标左键`；
   - 视口平移：`Alt + 鼠标中键`；
   - 视口缩放：`Alt + 鼠标右键`（或滚轮）；
   - 视口重置聚焦：快捷键 `F`；
   - **核心神技（旋转环境光照 HDRI）**：按住 **`Shift + 鼠标右键水平拖动`**，亲眼观察天光高光在球人身上的流动；
3. **纹理集列表 (Texture Set List)**：
   - 指向右上角，点击切换 `Head`、`Body`、`Base`；
   - 明确第一讲全员任务**严格聚焦于 `Head`**，暂不分散精力到其他部位；
   - **教材对应来源指针**：`zheng-2024-painter` §2.10 纹理集列表（印刷页 62~65 / 物理页 72~75）。
4. **图层调板 (Layers) 与属性调板 (Properties)**：
   - 认识图层堆栈面板，以及控制物理通道的属性面板；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9 图层调板概述（印刷页 46~47 / 物理页 56~57）。

### 2.3 阶段三：教师示范 (Instructor Demo — 15 分钟)
教师在投影屏幕上进行清晰、连贯的最小示范（仅限 Head 部位）：
1. **建立底层塑料材质 (Plastic Base)**：
   - 确保选中 `Head` 纹理集；
   - 点击图层面板上方的油漆桶图标 **`Add fill layer`**（添加填充图层）；
   - 双击命名为 `Plastic_Base`；
   - 在填充属性中，点击关闭不需要的 `nrm`（法线）与 `height`（高度）按钮；
   - 点击 `baseColor` 选取一个明亮黄色；
   - 将 `Roughness` 拖动至 `0.15`，`Metallic` 保持为 `0.0`；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9.3 填充图层（印刷页 48 / 物理页 58；图 2.81）。
2. **建立第二层覆盖材质与黑色遮罩 (Face Mask)**：
   - 再次点击油漆桶图标新建填充层，命名为 `Face_Mask`；
   - 设置 `baseColor` 为深蓝黑色，`Roughness` 为 `0.05`（全头被覆盖）；
   - 右键该图层，选择 **`Add black mask`**（添加黑色遮罩），整层瞬间隐藏；
   - 选中遮罩方块，按 `1` 键激活画笔工具，确认颜色为白色（1.0）；
   - 在面部平整区域涂抹，深色面罩随笔触清晰显现；按 `X` 切换黑画笔即可擦除纠错；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9.3 创建黑色遮罩与 §2.9.4 遮罩特效（印刷页 47, 51~54 / 物理页 57, 61~64）。

### 2.4 阶段四：学生动手跟练 (Student Hands-on Practice — 25 分钟)
- **学生任务**：在机房实操电脑上打开 MeetMat，跟随教师示范完成上述操作：
  1. 打开官方 MeetMat Sample；
  2. 尝试 `Alt+鼠标三键` 导航并旋转光照；
  3. 在 `Head` 部位亲手新建底层填充层，随意改变颜色，并将 `Roughness` 从 0.1 逐渐拖动到 0.9，亲眼观察高光光斑从锐利小点扩散为柔和光晕；
  4. 新建第二层并添加黑色遮罩，在面部画出一个简易面罩图案；
- **教师巡视**：流动检查每位学生机器是否正常，重点排除“建错手绘图层”、“没选中 Head 部位”等初始问题。

### 2.5 阶段五：理论解释与知识升华 (Theoretical Grounding — 20 分钟)
在学生刚亲手操作完、对滑块变化记忆犹新时，教师切屏进行直观物理概念与科学解释的升华：

```
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│                                PBR 核心概念直观教学映射模型                                  │
├───────────────┬───────────────────────────────┬──────────────────────────────────────────────┤
│ 物理通道      │ 直观生活化比喻                │ 严格科学与物理边界说明 (Scientific Boundary) │
├───────────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 能量守恒定律  │ 【家庭开支恒等式】光能预算固定│ 针对表面反射与内部散射分配。实际粗糙表面存在 │
│               │ 表面高光反射多，漫反射就少    │ 微表面二次弹射吸收损耗，需着色器能量补偿。   │
├───────────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 金属度二值性  │ 【导电与绝缘的世界】非黑即白  │ 电介质与导体复数折射率差异。微观氧化层或半导 │
│ (Metallic)    │ 绝缘体高光纯白，金属高光带颜色│ 体存在过渡，但在基础教学中严禁乱调成0.5。    │
├───────────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 微表面粗糙度  │ 【平静湖面 vs 砂纸表面】      │ 粗糙度决定 GGX 高光波瓣展宽。粗糙度增大光斑  │
│ (Roughness)   │ 湖面高光锐利，砂纸高光散开    │ 扩散但总光能守恒；大角度下伴随微表面自遮蔽。 │
├───────────────┼───────────────────────────────┼──────────────────────────────────────────────┤
│ 图层遮罩系统  │ 【多层喷漆与遮蔽胶带】        │ 数学本质为单通道标量灰度插值                 │
│ (Layer Mask)  │ 底漆上面喷面漆，胶带撕开露底层│ Lerp: Result = A * (1 - Mask) + B * Mask     │
└───────────────┴───────────────────────────────┴──────────────────────────────────────────────┘
```

1. **能量守恒定律与“高光会跑”**：
   - 刚才学生旋转天光时看到高光在移动，证明：**高光是视口和光源交互计算出来的反射光，绝不能手绘在 Base Color 固有色里**；
   - **教材对应来源指针**：`zheng-2024-painter` §1.3.2 能量守恒定律（印刷页 4~5 / 物理页 14~15）。
2. **金属度二值性 (Metallic 0 vs 1)**：
   - 绝缘体（塑料）高光没有颜色（纯白色）；导体（纯金属）高光带金属颜色且无漫反射底色；严禁将 Metallic 设为 0.5 灰度；
   - **教材与外部规范来源指针**：
     - 教材定性指针：`zheng-2024-painter` §1.3.2 通道定义(4)与 §1.4.1 金属度工作流（印刷页 5~6, 8~9 / 物理页 15~16, 18~19；原书仅作 0/1 黑白通道定性，未载具体微观反射率百分比数值）；
     - 物理反射率基准：绝缘体高光反射率通常 2%~5%（F0 0.02~0.05），纯导体高光反射率通常在 60%~90%（金银等可达 90%~95%），详见行业标准规范 *The PBR Guide (2018) Part 1* pp. 33–37。
3. **微表面粗糙度 (Roughness 0.0~1.0)**：
   - 结合刚才学生拖动滑块的体验：微观分子平整如湖面（Roughness=0）高光汇聚；微观凹凸如砂纸（Roughness=1）光斑扩散；
   - **教材对应来源指针**：`zheng-2024-painter` §1.3.1 微表面模型与通道定义(3)（印刷页 3~5 / 物理页 13~15）。
4. **图层与遮罩的心智模型**：
   - 填充图层 (Fill Layer) 是全通道参数容器；遮罩本质是单通道灰度线性插值 ($\text{Result} = A \times (1 - M) + B \times M$)；
   - **教材对应来源指针**：`zheng-2024-painter` §1.5 与 §2.9 图层调板概述（印刷页 10~11, 46~47 / 物理页 20~21, 56~57）。

### 2.6 阶段六：独立应用、反馈纠偏与持久化验证 (40 分钟)
- **独立设计 (25 分钟)**：学生根据自身创意，微调 Head 的塑料底色、粗糙度与面部遮罩图案，完成一份完整的个人 Head 材质；
- **四级反馈漏斗 (8 分钟)**：同桌互查 30 秒（转动天光核验高光是否流动、Metallic 是否为 0）+ 教师流动抽查典型问题；
- **持久化验证 (7 分钟)**：全员执行规范另存为 `.spp`，彻底关闭 Painter，重新双击打开核验工程完整性。

## 3. 全员核心任务与非必经目标定界 (Core Scope & Non-Goals)

为落实教师已接受决定，避免初学者在第一堂课认知过载，明确划定边界：

### 3.1 全员核心保底任务 (Mandatory Core Scope)
1. **资产范围限定**：严格限定于 **MeetMat 的 `Head`（头部）部位**；
2. **通道属性掌握**：亲手配置 Base Color（纯色无阴影）、Roughness（0.1~0.9 直观对照）、Metallic（严格保持为 0.0）；
3. **图层结构达成**：双层填充图层（`Plastic_Base` 底层 + `Face_Mask` 覆盖层）；
4. **空间局部控制**：成功添加黑色遮罩（Black Mask），使用画笔完成面部局部区域开窗与擦除纠偏；
5. **工程生命周期闭环**：保存为 `.spp` 工程文件，彻底退出 Painter 软件，重新双击打开核验图层与材质无丢失。

### 3.2 明确非必经目标 (Explicit Non-Goals / Optional Extensions)
以下内容明确**不属于第一讲必经目标，不设为随堂考核项，不强制要求全员完成**：
- **`Body` 与 `Base` 绘制**：仅限学有余力学生作为课外自愿探索，课堂时间不足时一律略过；
- **Smart Materials (智能材质)**：不要求学生在第一讲掌握或使用智能材质，避免过早陷入复杂预置图层黑盒；
- **Generators (生成器，如 Curvature/Dirt)**：第一讲不引入网格贴图驱动的生成器，留待后续塑料与金属课深入；
- **Iray 离线光追视口渲染 (`F10`)**：第一讲保持标准实时 PBR 视口，不把显卡发热与光追渲染作为必测项；
- **正式计分平时作业**：第一讲零正式平时作业，仅作形成性掌握度诊断。

## 4. 学生实践任务与成果证据 (Student Practice & Observable Evidence)

### 4.1 课堂实践任务与动手预算 (学生动手总预算 60 分钟)
在 160 分钟计划预算中，共为学生规划 **60 分钟的真实上手动手时间**，分为两个阶段：
1. **阶段一：基础跟练与手感建立 (Step 4，计划 25 分钟)**：
   - 载入 MeetMat，活动双手掌握 `Alt+鼠标三键` 导航与 `Shift+右键` 光照旋转；
   - 为 Head 部位建立第一层单色电介质塑料填充层并核验。
2. **阶段二：独立创作与个性化设计 (Step 6，计划 35 分钟；最低保护 25 分钟)**：
   - 学生基于 `MeetMat Head` 独立设计个性化塑料底色与面罩图案；
   - **基础目标 (全员保底)**：完成 Head 双层塑料填充层与黑色遮罩开窗绘制；
   - **进阶目标 (学有余力自愿选做)**：尝试探索 Body 部位或使用其他笔刷 Alphas。

### 4.2 学生轻量三字段材质决策记录 (Material Decision Card)
随堂记录本或机房记事本中记录 1 组直观物理决策：

### 5.2 现场超时剪裁规则 (Cut Rules)
在 35 人单师大班环境下，若遇到机器卡顿或学生进度滞后，严格执行以下剪裁优先级：
1. **优先剪裁项 (Cut 1)**：若开场机房登录消耗较多时间，**压缩 Block 1 课程介绍至 8 分钟**，仅保留核心考核边界与“本课只做材质”结论；
2. **次级剪裁项 (Cut 2)**：若学生在 Block 7 绘制遮罩耗时过长，**坚决不向 Body/Base 延伸**，收敛在 Head 单一部位完成双层材质即可；
3. **高级特性剪裁 (Cut 3)**：智能材质展示完全取消，现场仅使用标准实时 PBR 视口；
4. **绝对保护核心 (Protected Core)**：
   - **坚决保护 Block 5 & 7 学生实际上手动手时间（全场不少于 45 分钟）**；
   - **坚决保护 Block 8 保存退出重开验证（不少于 8 分钟）**；
   - **严禁通过“留隐性课后作业”来吸收课堂超时**。

### 5.3 四级反馈漏斗与大班管理
- **Level 1 (广播共性纠偏)**：发现 3 名以上同学出现同类错误（如 Metallic 调成 0.5），立刻广播切屏暂停 1 分钟纠偏；
- **Level 2 (同桌 30 秒互查)**：同桌互相旋转对方视口光照：高光是否流动？Metallic 是否为 0？
- **Level 3 (流动靶向抽查)**：教师在机房走动，专门辅导后排或举手卡壳学生；
- **Level 4 (工程抽样异步核验)**：课后随机抽查 5–10 份提交的 `.spp`，检查图层命名与通道设置规范度。

### 6.2 工程保存、退出与重开持久化规范
1. **标准命名规则**：
   - 统一保存在本机学生作业盘（如 `D:\GR2102_2026\Week1\`）；
   - 命名格式：`GR2102_W1_班级_学号后两位_姓名_MeetMat.spp`；
2. **退出重开持久化验证三步法**：
   - 第一步：按 `Ctrl + S` 保存工程；
   - 第二步：**彻底退出 Substance 3D Painter 进程**；
   - 第三步：双击刚才的 `.spp` 文件重新打开，核验图层与遮罩完整无损。

### 6.3 路径对比与最稳妥方案推荐 (Starter vs From Scratch)
针对第一讲 MeetMat 实施，对比两条路径的实际操作成本：

| 对比维度 | 路径 A：预置学生 Starter (`MeetMat_Starter.spp`) | 路径 B：课堂从零建立图层 (官方内置 Sample) |
| :--- | :--- | :--- |
| **开局准备与网络分发** | 教师需提前制作 `.spp` 并通过机房广播或网络分发至 35 台电脑，存在分发丢包或路径损坏风险。 | **零准备成本**：官方原生内置 Sample（`File -> Open Sample... -> MeetMat`），断网亦可原生打开。 |
| **向下兼容版本风险** | **极高**：若教师制作工程的版本高于机房机器版本，学生端打开将直接弹窗报错拒绝加载。 | **零版本风险**：各版本 Painter 均能无缝加载自身自带的内置示例。 |
| **操作成本与认知收益** | 开局已有图层，但学生失去了“图层堆栈从无到有”的认知建构机会，产生黑盒依赖。 | **仅需点击 2 次**（油漆桶加层 $\to$ 调参），学生亲手建层，空间与通道心智完全透明。 |
| **故障恢复定位** | **适合作为 Tier 3 严重掉队保底 (Recovery Asset)** | **【强烈推荐作为第一讲全员主干路径】**：零分发摩擦、零版本风险、亲历建层。 |

- **推荐结论**：**全员采用路径 B（官方内置 MeetMat，学生亲手从零建层）；仅将路径 A 作为极个别机器卡壳学生的 Tier 3 救急保底资产**。
