## 1. 教学定位与整体介绍 (Course Orientation & Lesson 1 Scope)

### 1.1 课程宏观定位与开场声明 (Course Orientation — 15 分钟)
作为 9 周连堂课程的第一周开场，主讲教师需用前 15 分钟向学生明确课程的宏观图景与红线，解除学生的先修焦虑：
1. **核心聚焦材质本身 (Material / Texture Authoring)**：
   - 本课程的核心使命是学习**物理真实（PBR）材质创作与贴图绘制**；
   - 建模、人体拓扑、高低模包裹、展 UV 是材质制作的**支撑性前置知识**，教师会在后续课程中提供展开良好、法线干净的规范工业与雕像资产。课程绝不会在第 3 讲突然让学生手动画肌肉拓扑来作为考核难点；
2. **九讲能力演进阶梯**：
   - 从第 1 讲的 MeetMat 入门认知，到塑料、木材、金属、石材、织物、次表面半透明与自发光，最终在第 7–9 周完成全新独立的综合期末大作业；
3. **考核评价导向说明 (不冻结具体比例)**：
   - 课程遵循“最终作品质量优先”原则，同时重视课堂内的物理因果理解与过程证据；
   - **第一讲声明**：第 1 讲不设正式计分平时作业，以“熟悉软件环境、掌握物理通道、建立正确保存习惯”为考核前哨。

### 1.2 为什么第一讲选用官方 MeetMat 资产？
- **零门槛标准几何体**：`MeetMat` 是 Allegorithmic / Adobe 官方为材质挑战赛定制的标杆测试模型；
- **分层材质集 (Texture Sets)**：模型天然划分为 `Head`（头部）、`Body`（身体）、`Base`（底座）三大纹理集，能够让初学者在第一堂课直观理解多材质球与模型部位的解耦关系；
- **规范的 UV 与网格烘焙**：内置资产已预置高质量曲率（Curvature）、环境遮蔽（AO）与法线（Normal）贴图，杜绝外部资产因尺寸异常、法线翻转或缺少烘焙贴图导致的生成器失效问题，实现“开箱即用”。

### 2.1 能量守恒定律：不要把高光“画死”在底色里
- **直观讲解**：光线照到物体表面就像领到一笔固定的“光能预算”。这笔预算一部分被表面直接弹走（镜面高光反射），一部分钻进物体浅表层乱撞后再射出来（漫反射底色）。高光反光强了，留给底色的能量就必须变少。
- **核心操作警示**：**“高光会跑，别把光影画死在 Base Color 里”**。初学者最容易犯的错误是在 Base Color 贴图上手绘白色高光点和黑色阴影。教师必须现场转动环境光（`Shift + 鼠标右键`），让学生亲眼看到：光线一转，高光光斑跟着跑动；如果手绘在底色上，就会出现“光源转了但高光死在脸上”的假假穿帮。
- **教材对应来源指针**：`zheng-2024-painter` §1.3.2 能量守恒定律（印刷页 4~5 / 物理页 14~15）。

### 2.2 金属度 (Metallic 0 vs 1)：电介质与导体的分水岭
- **直观讲解**：世界上绝大多数材质可清晰分为绝缘体（塑料、木头、泥土、橡胶、皮肤，Metallic=0）与导体（铁、铜、金、铝，Metallic=1）。
  - 绝缘体：高光很弱（仅约 2%~5% 反射率），且**高光完全没有颜色（纯白色）**；
  - 纯金属：完全没有漫反射底色（漫反射光能被电子全部吸收），高光极强（60%~95% 反射率），且**高光带有金属自身的颜色**（黄金高光偏黄、紫铜高光偏红）。
- **教学红线**：禁止初学者将 Metallic 当成“增强反光的滑块”推到 0.4~0.6。除非表现锈蚀边缘或极薄灰尘混合，否则 Metallic 必须坚决保持 0 或 1。
- **教材对应来源指针**：`zheng-2024-painter` §1.3.2 通道定义(4)与 §1.4.1 金属度/粗糙度工作流程（印刷页 5~6, 8~9 / 物理页 15~16, 18~19；图 1.6, 1.7, 1.11）。

### 2.3 粗糙度 (Roughness 0.0~1.0)：微观平整度
- **直观讲解**：粗糙度并不改变宏观形状，而是改变微观分子级别的平整度。Roughness=0 就像完全平整的镜面或冰面，高光收敛成一个耀眼的小锐点；Roughness=1 就像磨砂粗陶或粉笔，光线被微观坑洼朝四面八方弹射，高光被拉伸得极大、极散、极柔和。
- **教材对应来源指针**：`zheng-2024-painter` §1.3.1 微表面模型与通道定义(3)（印刷页 3~5 / 物理页 13~15；图 1.1, 1.2, 1.5）。

### 2.4 图层与遮罩心智模型 (Layer Stack & Mask)
- **心智模型转换**：Painter 并不是 Photoshop。Photoshop 处理的是一张 2D 像素图片；Painter 处理的是一整套并行的**物理属性层叠立方体**（每层同时包含 Base Color、Roughness、Metallic、Normal、Height）。
- **填充图层 (Fill Layer) 优先原则**：
  - 手绘图层 (Paint Layer)：一旦画下像素就固化，改颜色需重新涂抹；
  - 填充图层 (Fill Layer)：基于参数生成，随时可双击修改颜色、粗糙度或金属度；
  - 遮罩 (Black Mask)：用黑（0）白（1）灰度图控制当前图层在哪些三维区域显现。
- **教材对应来源指针**：`zheng-2024-painter` §1.5 什么是 Substance 3D Painter 与 §2.9 图层调板概述（印刷页 10~11, 46~47 / 物理页 20~21, 56~57）。

## 3. 教师操作示范准确步骤 (Step-by-Step Instructor Demo — RUNTIME REQUIRED)

> [!IMPORTANT]
> **运行时门禁说明 (`RUNTIME REQUIRED / OPEN`)**：以下示范步骤系依据官方工作流规范设计。因本地宿主未部署 Painter 独立应用，所有按钮、快捷键、截图导出与持久化重开流程，在本地严格保持为 `RUNTIME REQUIRED / UNVERIFIED ON LOCAL HOST`，必须在开课前于真实机房目标 PC 上完成实机探针验证。

建议分为两段演示（各 15–20 分钟），中间穿插学生跟随动手，避免长时被动记忆。

### 第一段示范：环境认知、Texture Set 与第一个填充图层 (20 分钟)
1. **启动与创建项目**：
   - 打开 Substance 3D Painter；
   - 点击菜单 `File -> Open Sample...`，在弹出的官方示例列表中双击选中 **`MeetMat`**（或从 New Project 模板选择）；
   - 确认工作区视口正常载入可爱的 MeetMat 球人模型。
2. **视口导航与手感建立 (必须让学生全体活动双手)**：
   - `Alt + 鼠标左键`：围绕模型 360 度旋转观察视口；
   - `Alt + 鼠标中键`：视口平移拖拽；
   - `Alt + 鼠标右键`（或滚轮）：视口平滑推拉缩放；
   - `F` 键：聚焦居中当前选中部件；
   - **核心神技**：按住 **`Shift + 鼠标右键水平拖动`**：旋转三维环境全景光照（HDRI 天空盒），观察高光在头盔与底座上的流动。
3. **认识纹理集列表 (Texture Set List)**：
   - 引导视线至右上方 `Texture Set List` 面板；
   - 点击 `Head`、`Body`、`Base`，观察视口高亮反馈，解释这就是三套独立的贴图与材质球系统；
   - **教材对应来源指针**：`zheng-2024-painter` §2.10 纹理集列表与 §2.11 纹理集设置（印刷页 62~65 / 物理页 72~75；图 2.117~2.122）。
4. **创建第一个无损填充图层 (Fill Layer)**：
   - 在 `Texture Set List` 选中 `Head`（头部）；
   - 在右下方 `Layers`（图层）面板中，点击油漆桶图标 **`Add fill layer`**（添加填充图层）；
   - 将新图层双击重命名为 `Plastic_Base`（塑料底色）；
   - 向下滚动到 `Properties: Fill`（填充属性）面板，点击关闭不需要的 `nrm`（法线）和 `height`（高度）通道按钮（变暗即关闭）；
   - 单击 `baseColor` 颜色块，在拾色器中挑选一个明亮的黄色；
   - 拖动 `Roughness` 滑块至 `0.15`（光滑微反光）；
   - 确认 `Metallic` 保持为 `0.0`；
   - 视口即刻呈现通透鲜亮的黄色烤漆塑料质感；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9.3 创建图层(2)填充图层（印刷页 48 / 物理页 58；图 2.81）。

### 第二段示范：遮罩分区、材质叠层与智能材质解构 (20 分钟)
1. **添加第二层覆盖材质**：
   - 依然在 `Head` 部位，点击油漆桶图标再次新建一个填充图层，重命名为 `Face_Visor`（面部面罩）；
   - 将 `baseColor` 设为深邃的蓝黑色，`Roughness` 设为 `0.05`（极度平整光滑如镜）；
   - 此时整个头部被完全盖成蓝黑色。
2. **添加黑色遮罩与绘制开窗**：
   - 右键点击 `Face_Visor` 图层，在弹出菜单中选择 **`Add black mask`**（添加黑色遮罩）；
   - 解释：黑色遮罩将整层遮挡，头部重新露出底层的黄色塑料；
   - 左键单击该黑色遮罩图标（确保白色方框选中遮罩，而非材质材质球）；
   - 在左侧工具栏激活画笔工具（快捷键 `1`），在下方属性中确认画笔颜色为纯白（灰度值 1.0）；
   - 按住 `Ctrl + 鼠标右键水平拖动` 调节画笔大小，在 MeetMat 的面部平整区域涂抹，黑色面罩随笔触显现出来；
   - 提示：若涂出界，按快捷键 `X` 切换画笔颜色为纯黑，即可像橡皮擦一样擦除错误；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9.3 创建遮罩(2)添加黑色遮罩与 §2.9.4 遮罩和特效（印刷页 47, 51~54 / 物理页 57, 61~64；图 2.79, 2.92, 2.93）。
3. **跨部件材质与智能材质初探**：
   - 切换到 `Base`（底座）纹理集；
   - 在左下方 `Assets`（资产库）点击 `Smart materials`（智能材质）图标；
   - 挑选一个官方预设（如 `Steel Gun Painted` 或 `Bronze Armor`），直接拖拽到底座图层面板中；
   - 展开该智能材质文件夹，向学生揭秘：“智能材质不是黑魔法，它本质上就是别人做好的多层填充图层 + 自动计算边缘磨损的遮罩！”；
   - **教材对应来源指针**：`zheng-2024-painter` §2.9.4 智能遮罩与 §2.20.3 资源类型说明（印刷页 54, 89~90 / 物理页 64, 99~100；图 2.99）。

### 4.1 课堂实践任务与动手预算 (学生动手总预算 60 分钟)
在 160 分钟连堂中，共为学生规划 **60 分钟的真实上手动手时间**，分为两个递进阶段（严格对应后文 5.1 节时间切片预算）：

2. **阶段二：独立创作与个性化设计 (Block 6，计划 35 分钟；最低保护 25 分钟)**：
   - 学生基于 `MeetMat` 独立设计一套**双材质以上对比**的质感搭配；
   - **基础目标 (全员保底)**：
     1. 为 `Head` 赋予具有鲜明固有色的电介质塑料材质（Metallic=0, Roughness 适中）；
     2. 使用黑色遮罩为面部或局部花纹绘制至少 1 处清晰的区域划分；
     3. 为 `Body` 或 `Base` 赋予一种粗糙或带有金属感的材质；
   - **进阶目标 (学有余力候选)**：
     - 尝试在遮罩上添加生成器（Add generator $\to$ Dirt / Curvature），观察边缘磨损效果；
     - 尝试按 `Tab` 键进入全屏查看模式，或按 `F10` 启动 Iray 光追预览查看真实阴影。

## 5. 160 分钟候选节奏、超时剪裁与反馈方法 (Timing, Cut Rules & Feedback)

### 5.1 候选时间切片计划预算 (160 分钟全景 / PLAN BUDGET，非已实测容量)

| 阶段 | 建议时间 | 活动主题 | 教师活动 | 学生活动 | 产出与检查点 |

### 5.2 现场超时剪裁规则 (Cut Rules)
在 35 人单师大班环境下，若遇到机器卡顿或学生进度滞后，严格执行以下剪裁优先级：
1. **优先剪裁项 (Cut 1)**：若开场机房登录或软件启动消耗较多时间，**压缩 Block 1 课程介绍细节至 8 分钟**，仅保留核心考核边界与“本课只做材质”结论；
2. **次级剪裁项 (Cut 2)**：若学生在 Block 6 绘制遮罩耗时过长，**取消 Body 和 Base 的多部件要求**，将任务收缩为“只需完整做出 Head 的双层材质与遮罩绘制”即算完成核心闭环；
3. **高级特性剪裁 (Cut 3)**：智能材质解构与 Iray 光追视口预览降级为**课后选做或下周延伸**，现场仅使用标准 PBR 视口；
4. **绝对保护核心 (Protected Core)**：
   - **坚决保护 Block 6 独立动手时间（不低于 25 分钟）**；
   - **坚决保护 Block 8 保存退出重开验证（不低于 8 分钟）**；
   - **严禁通过“留隐性课后作业”来吸收课堂超时**。

### 5.3 四级反馈漏斗与大班管理
针对 35 人班单教师无法逐人辅导的物理极限，采用四级漏斗模式：
- **Level 1 (广播共性纠偏)**：教师发现有 3 名以上同学出现同类错误（如在 Base Color 里选带阴影的颜色），立刻广播切屏暂停 1 分钟，全班纠偏；
- **Level 2 (同桌 30 秒互查)**：让左邻右舍互相查看对方的视口：转动光照时高光是否流动？Metallic 是否保持 0 或 1？
- **Level 3 (流动靶向抽查)**：教师在机房走动，只针对后排、反应迟缓或报错举手的同学进行针对性微指导；
- **Level 4 (工程抽样异步核验)**：课后随机抽查 5–10 份提交的 `.spp`，检查图层命名与通道设置规范度，作为下周开课讲评素材。

### 6.2 工程保存、退出与重开持久化规范
为彻底避免“下课前软件崩溃导致全天白做”或“存了文件下周打不开”的灾难：
1. **标准命名规则**：
   - 必须统一保存在本机学生作业盘（如 `D:\GR2102_2026\Week1\`）；
   - 文件命名格式：`GR2102_W1_班级_学号后两位_姓名_MeetMat.spp`；
   - 示例：`GR2102_W1_01班_08号_张三_MeetMat.spp`；
2. **退出重开持久化验证三步法**：
   - 第一步：按 `Ctrl + S` 保存工程，等待右下角进度条走完；
   - 第二步：**直接点击窗口右上角彻底退出 Substance 3D Painter 进程**；
   - 第三步：进入保存目录，双击刚才的 `.spp` 文件重新打开。检查：图层面板是否都在？颜色和粗糙度是否完整？确认无误后再打包提交截图。

### 6.3 机房环境三级容灾梯队 (Lab Fallback Tiers)
针对学校老旧教学机房可能出现的硬件卡顿与显卡发热：
- **Tier 1 (理想环境)**：开启标准抗锯齿、视口阴影、尝试 Iray 光线追踪预览（`F10`）；
- **Tier 2 (标准降级 - 推荐默认)**：关闭视口后期处理特效（Displacement / Bloom），将视口采样保持在默认水平，保持纯视口 PBR 预览；
- **Tier 3 (极致保底 - 老旧低显存机器)**：
  - 在 `Texture Set Settings` 面板中，将工作分辨率从 2048 临时降至 **`1024`** 进行流畅绘制；
  - 关闭不需要的通道显示，避免多图层复杂生成器运算。
