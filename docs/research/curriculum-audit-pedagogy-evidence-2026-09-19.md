# 八周本科材质课：教学设计证据与适用边界

核查日期：2026-09-19。用途：独立审查的外部教学依据，不是项目 Gate、既有架构或排课数字的认证。

方法：使用 agent-reach / Exa 定位官方来源；Jina Reader 读取失败（curl exit 6）后用 web 读取原站。未读取项目已有独立审查；未核验项目的工时、学生表现或达标率。下列大学页面属于机构原发教学指导；Kidd 属于作者原文的文献综述，不是原始实验，不能冒充因果证据。

## 用于审查的四个问题（本次推论）

1. **Feedback**：是否有实际作品、明确标准、针对差距的反馈、学生据此修改及再检查的机会？安排了点评时间尚不能证明反馈已发生或被使用。
2. **Component integration**：学生是否在得到支架后亲自整合观察、材质判断、贴图/着色器、导出与呈现？组件练习与最终成品之间是否存在可执行的整合练习？
3. **Transfer**：学生是否在未逐步示范的新条件中选择方法、解释适用边界并完成任务？复刻教师流程与迁移是不同证据；这些指导未给出一个可直接套用的迁移通过阈值。
4. **Workload**：演示、初学者操作、失败恢复、反馈、修订与独立评价是否都占用了真实时间？排课算术只能说明预算被分配，不能证明学生能完成；缺试教数据时应保留不确定性。

## 防止反向过度推断

这些来源既不证明现有课表充分，也不证明它必然不可教。缺少记录是可验证性缺口，不等于学生能力必然不足。补齐文件也不会自动补齐练习机会、教师反馈容量或软件操作时间。应把审查中发现的文件缺口、教学设计风险与实测学习失败分别表述。
