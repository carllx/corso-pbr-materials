## 热身练习：原生几何体视口初探与高光观察 (Block 3: Geometry Warmup)

> [!NOTE]
> **热身练习说明（无压力手感建立）**：  
> 本热身练习旨在帮助零基础同学提前建立 Blender 视口操作手感与光影直观认知。  
> **重要纪律：本环节不单独评分、无需提交工件、不要求精确复刻教师屏幕！**

1. **打开热身工程**：双击打开桌面或课件包中的 `warmup/W1_Warmup_Geometry_Starter.blend`；工程中已预置磨砂对比立方体（`Warmup_Cube`，粗糙度 0.6）；
2. **学生最小动手操作（约 2 分钟建立手感）**：
   - **亲手添加球体**：鼠标置于 3D 视口，按快捷键 `Shift + A` $\to$ **Mesh** $\to$ **UV Sphere**，添加一个原生球体；
   - **亲手位移摆放**：按快捷键 `G`（或 `G` 之后按 `X`），将球体向左移开一段距离，与右侧立方体并排；
   - **指派预置材质**：选中新球体，在右侧属性栏点击 **Material (材质属性)** 图标，在材质槽下拉菜单中直接选择工程已预置好的 **`Mat_Warmup_Sphere`**（光滑中性灰材质，无需搭建节点，一秒完成指派！）；
3. **视口导航手感三键客**：
   - 鼠标中键按住拖动：**旋转视口**（Orbit）；
   - `Shift` ＋ 鼠标中键拖动：**平移视口**（Pan）；
   - 鼠标滚轮推拉：**缩放视口**（Zoom）；
4. **认识材质预览模式 (Material Preview)**：
   - 确认右上角视口着色方式处于第 3 个圆球图标 **材质预览模式 (Material Preview)**；
   - **灯光直观机制**：该模式由 Blender 内置中性 HDRI 环境提供光照，**默认不启用场景中的灯光 (use_scene_lights=False)**，因此无需调整场景灯光；
5. **亲手验证“高光会跑”与粗糙度差异**：
   - 观察球体表面锐利集中的反光点，对比右侧立方体表面扩散漫散的磨砂光晕；
   - 用鼠标中键缓慢旋转视口视角，观察高光斑的位置：**随着视角改变，高光斑在表面滑动！**
   - **核心记忆锚点**：“**高光会跑，别把它画死在 Base Color 里！**”
6. **容灾分支 (Fallback)**：若添加物体或查找面板卡顿超过 2 分钟，可在右上角大纲视图 (Outliner) 展开 `Fallback_Backup` 集合并点亮眼睛图标显示备用球体 `Warmup_Sphere_Fallback`，直接跳过添加步骤进入旋转观察，保护后续手电筒主线时间。完成热身即可进入正式案例观察。

## 任务 B：上机动手——首个有界材质决策与修订 (LO2 雏形)

#### 本周核心概念与有界术语 (W1 Terminology Anchors)
- **Material Preview (材质预览模式)**：Blender 视口使用 EEVEE 引擎与内置 HDRI 环境贴图提供中性预览光照，默认不启用场景灯光，无需手动打光即可看清反射与质感；
- **Base Color (基础颜色 / 固有色)**：物体材质表面的反射基色，大白话“剥离所有光影后的原本颜色”；核心记忆锚点：“高光会跑，别把它画死在 Base Color 里”；
- **Roughness (粗糙度)**：微表面微起伏程度，大白话“表面糙不糙、反光散不散”。值低高光锐利如镜，值高高光模糊哑光；
- **Metallic (金属度)**：材料导体属性，大白话“是不是金属（非黑即白）”。金属无漫反射固有色，非金属才具有 Base Color 漫反射；
- **Normal (法线)**：表面微观朝向，大白话“不用加面数，假装表面有凹凸凹陷”；
- **Shader Editor (着色器编辑器)**：屏幕下方用于控制材质逻辑的蓝图窗口；
- **Node (节点)**：着色器中的独立功能块（如预置的 `Body_Color_Tint` 节点），左侧接收输入，右侧输出计算结果；
- **Connection / Data Flow (连接与数据流)**：节点之间的彩色连线，代表贴图与色彩数据从左向右流经运算并注入着色器端口；
- **Multiply (正片叠底 / 相乘)**：将两路输入颜色逐通道相乘的算法。纯白 $(1,1,1)$ 为乘法中性元（相乘后保持原色完全不变），深色/有色则会产生压暗与染色叠加；
- **Factor (混合因子)**：控制相乘染色混合程度的无量纲滑块（`0.0` 为完全不染色的原贴图外观，`1.0` 为完全相乘染色的外观）。**注意：这是一种有界色彩叠加调节 (Bounded Color Adjustment)，不是物理上的涂层厚度或真实喷漆覆盖率！**
- **Transmission vs Alpha**：玻璃透光折射 (Transmission) ≠ 贴图表面遮罩/镂空 (Alpha)。
